# Drafting Skill

## Overview

Use this skill to draft content, messages, proposals, and communications.

## When to Use

- Writing a proposal or spec
- Drafting Discord announcements
- Composing emails or reports
- Preparing changelogs or release notes

## Workflow

1. **Purpose**: Why is this being written?
2. **Audience**: Who reads it and what do they need?
3. **Structure**: Outline key points
4. **Draft**: Write in the right tone
5. **Edit**: Cut fluff, sharpen claims

## Tone Guidelines

- Hive: Direct, declarative, no fluff
- Beau: Evidence-based, conservative
- Kilo: Action-oriented, terse
- Scribe: Structured, archival
- Edgeless CC: Technical, precise
- Pamela: Data-driven, risk-aware
- Critic: Rigorous, skeptical

## Verification

- [ ] Purpose clear in first sentence
- [ ] Tone matches audience
- [ ] No unverified claims
- [ ] Length appropriate for channel
