# Planning Skill

## Overview

Use this skill to create plans, roadmaps, and project breakdowns.

## When to Use

- Starting a new project or initiative
- Breaking down a large task
- Estimating timelines
- Defining milestones and deliverables

## Workflow

1. **Goal**: Define the objective and success criteria
2. **Constraints**: Time, budget, resources, dependencies
3. **Breakdown**: Split into phases and tasks
4. **Sequence**: Order by dependency and priority
5. **Buffer**: Add margin for uncertainty

## Plan Format

```markdown
# Plan: [Name]

## Objective
What we are doing and why

## Success Criteria
Measurable outcomes

## Phases
1. **Phase 1 — [Name]**: Tasks, timeline, owner
2. **Phase 2 — [Name]**: ...

## Risks
- [Risk] → Mitigation

## Dependencies
What must happen first
```

## Verification

- [ ] Every task has an owner
- [ ] Timeline includes buffers
- [ ] Dependencies identified
- [ ] Risks have mitigations
